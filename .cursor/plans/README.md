# Cursor plans (this repo)

All plans for **varc-portal** live in this folder: `.cursor/plans/`.

## Convention

1. Do **not** leave project plans only under `~/.cursor/plans/`.
2. If Cursor writes a new plan to the global folder, **move** it here (`mv`, not copy).
3. Edit existing plans in place under this directory.
4. Leave other repos’ plans in `~/.cursor/plans/` untouched.
